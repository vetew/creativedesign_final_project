# The Polite Calculator

A software prototype for the Creative Design course (University of Oulu, 2026). Target emotion: **surprise**.

The Polite Calculator looks like an ordinary calculator, but it refuses to give an answer until you say "please".

## How it works

- Press `=` without "please" and the calculator refuses: "Ahem. Aren't you forgetting something?"
- Type "please" in the reply box and you get the answer.
- Keep pushing and it gives a wrong answer on purpose.
- "Thank you" makes it happier and faster. Rude words lock it until you say "sorry".

## Running it

Open `index.html` in any web browser. No installation or server needed.

## For test leaders

Press `Shift + T` (or click "Calc 3000" three times) to open a hidden panel with the calculator's mood and a timestamped event log.
